# FlowDesk Design Principles

## Keep The Workspace Calm

Developer tools should feel powerful without feeling noisy. Use clear hierarchy, predictable controls, and restrained animation.

## Prefer Familiar Patterns

Compiler, diff, notes, snippets, and boards should look close enough to known developer tools that users understand them immediately.

## Make Mobile Useful

Mobile layouts should avoid squeezed desktop panels. Use tabs, drawers, sticky actions, and single-column flows when space is tight.

## Show State Clearly

Loading, saving, running, quota limits, payment state, and errors should be visible and specific. Avoid silent failures.

## Protect The User

Warn before destructive actions, keep delete controls consistent, and make privacy/payment terms reachable before purchase.

## Optimize For Return Visits

Remember useful context: selected notes, compiler files, AI sessions, task projects, and sidebar state when it improves flow.
